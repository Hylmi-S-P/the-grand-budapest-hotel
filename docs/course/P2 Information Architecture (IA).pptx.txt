Apa Itu 
User Flow?

User Flow adalah gambaran langkah-langkah yang dilakukan pengguna untuk mencapai suatu tujuan dalam aplikasi atau website.

Contoh tujuan:
"Pengguna ingin membeli makanan."
Jadi:
IA menjelaskan struktur sistem.
 User Flow menjelaskan perjalanan pengguna di dalam struktur tersebut.


User Flow sederhana biasanya hanya menunjukkan: 
Happy Path / Primary Flow

Padahal dalam dunia nyata, pengguna tidak selalu mengikuti jalur ideal.

Misalnya saat checkout:
pengguna berhasil membayar
pengguna salah memasukkan PIN
saldo tidak cukup
koneksi internet terputus
pembayaran gagal
pengguna membatalkan transaksi

Oleh karena itu, dibagi menjadi 3 Jenis Flow:
1. Primary Flow
2. Alternate Flow
3. Error Flow

Dari Basic User Flow ke Advanced User Flow

Primary Flow
Primary Flow adalah jalur utama yang paling diharapkan terjadi ketika pengguna berhasil mencapai tujuannya.

Sering disebut juga:
Happy Path
Main Flow
Ideal Flow
Contoh 
Goal: Pengguna ingin 
membeli tiket bioskop.
*semuanya berjalan sesuai harapan.

Alternate Flow
Alternate Flow adalah jalur alternatif yang masih valid dan tetap memungkinkan pengguna mencapai tujuan.
Contoh: 
pengguna ingin membeli makanan.

Alternate

Keduanya benar.
Bedanya hanya cara pengguna mencapai tujuan.

Error Flow
Error Flow adalah alur yang terjadi ketika terdapat kesalahan, kegagalan, atau kondisi tidak sesuai harapan.
Contoh Error Flow
Error Flow yang baik tidak hanya mengatakan:
❌ "Error!"

Tetapi memberikan informasi yang berguna:
✅ "Password yang kamu masukkan salah. Coba lagi."
