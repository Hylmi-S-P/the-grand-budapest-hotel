# MobilJuragan MVP

Prototype rental mobil untuk CV. Mobil Juragan Express Transport di Merauke, Papua Selatan.

Repositori ini berisi:

- `docs/` - dokumentasi, IA, user flow, dan screenshot Figma.
- `reasonix.toml` - konfigurasi agent workspace.

## Status

Project baru mulai. Repo mengikuti keputusan teknis yang tercatat di `docs/PLANNING_TECH_STACK_DAN_ROADMAP.md`.

## Stack

- Mobile: Flutter + Dart
- Web dashboard: Next.js + TypeScript
- Backend: Express.js + TypeScript
- Database: PostgreSQL + Prisma

Pembagian kerja, logbook AI-assisted, dan aturan kontribusi AI ada di:

- `docs/TEAM_WORK_ALLOCATION.md`
- `docs/TEAM_POLICY_AI-ASSISTED_DEVELOPMENT.md`
- `docs/LOGBOOK_AI_ASSISTED_TEMPLATE.md`
